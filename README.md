# CareJobs Healthcare Jobs (WordPress plugin)

Show a live list of open US healthcare jobs, with the pay each employer posts, on any WordPress site: a nursing or allied health school, a healthcare association, a workforce board, a staffing blog or a local newsroom. Filter by kind of job, state and keywords. Each job links to its page on [CareJobs.Now](https://carejobs.now), where the reader applies.

Free, no account and no API key. A block, a shortcode and a classic widget:

```
[carejobs_jobs kind="nurses" state="TX" limit="10"]
```

Kinds of job: nurses, nurse-practitioners, physicians, nursing-assistants, caregivers, therapy-rehab, mental-health, pharmacy, imaging, lab, surgical-techs, emts-paramedics, medical-assistants, dental, admin, allied-health, ai-training.

The full documentation, the shortcode attributes and the external service disclosure are in [readme.txt](readme.txt). Results are cached for an hour; nothing about your visitors is sent.

Download the installable zip from the [latest release](https://github.com/yumaheymans/carejobs-wordpress-plugin/releases/latest) and upload it under Plugins, Add New, Upload Plugin.
